# Swedad – Blocket Clone

Swedad is a learning project that mimics the functionality of [Blocket](https://blocket.se).  
It is **not intended for commercial use** and exists purely for educational purposes.

## 🚀 Tech Stack

- **Frontend:** React (Vite + TypeScript)
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **ORM:** Prisma

## 📚 About

This project was created to practice building a full-stack web application.  
It allows users to interact with a marketplace-like platform, similar to Blocket, but in a simplified way.

### Features (Planned / Implemented)

- User authentication
- Posting ads
- Browsing listings
- Database persistence with PostgreSQL & Prisma
- REST API built with Express
